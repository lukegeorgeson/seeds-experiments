# Visual Direction

## Purpose

Define the intended look and feel for Seeds v1.

## Design goal

Seeds should feel calm, sharp, and premium. It should read as a creative tool for thinking, not a playful whiteboard and not a noisy AI console.

## Core qualities

- spacious
- editorial
- restrained
- precise
- warm enough to invite exploration

## Visual tension to hold

The product should combine:
- canvas openness
- interface discipline

It should not look like:
- a generic SaaS dashboard
- a neon AI playground
- a sticky-note wall

## Recommended v1 decisions

- `recommended v1 decision`: support both light and dark mode, but keep light as the primary reference for layout tuning.
- `recommended v1 decision`: favor neutral foundations with one intentional accent color.
- `recommended v1 decision`: let typography and spacing do most of the premium work, not decorative chrome.

Current accent:

- `#eac1f5`

## Surface hierarchy

- app background should be quiet and lightly textured or tonal
- columns should be subtly delineated
- cards should be the main visual objects
- controls should recede until needed

## Motion guidance

- subtle streaming reveals
- light hover and selection motion
- restrained transitions between rounds
- soft blur-in and text-manifestation effects are acceptable when used sparingly on arriving cards

Avoid:
- bouncy motion
- overdone AI loading theatrics
